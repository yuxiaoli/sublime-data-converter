## Project Structure

- `src/`: Source code and application logic.
  - `src/utils/`: Shared helper modules and utility functions.
- `tests/`: Unit and integration test suites.
- `data/`: Data files, schemas, and static assets. E.g., `data.example.json`, `data.schema.json` and `data.schema.ts`.
- `docs/`: Design documentation and guides.
- `logs/`: Application execution logs.
- `scripts/`: Utility and automation scripts (e.g., `build.sh`, `deploy.bat`).
- `refs/`: Reference materials and external code snippets.
- `context/`: Contextual information for AI assistance (e.g., `SHELL.md` and `PROJECT_STRUCTURE.md`).
- `configs/`: Configuration files (e.g., `config.json`, `config.yaml`).
- `prompts/`: AI prompt templates and instructions (e.g., `prompt.txt` or `prompt.md`).
- `temp/`: Temporary artifacts (ignored by version control).
  - `temp/output/`: Temporary output files, e.g. HTML files.
  - `temp/results/`: Temporary result files, e.g. JSON files.
  - `temp/build/`: Temporary build files and artifacts, e.g. built skill files and installer packages.
